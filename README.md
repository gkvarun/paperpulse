# PaperPulse

A free Cambridge exam-preparation platform prototype for students from Class 7 to A Levels.

## Project source

The React/Vite app, Cloudflare Worker starter, D1 schema, and setup notes are included in the project source archive committed alongside this README.

## Run locally

Extract the project archive, enter the `paperpulse-react` folder, then run:

```bash
npm install
npm run dev
```

Requires Node.js 20 or newer. Build with `npm run build`.

## Important

This is a prototype, not a deployed production service. Authentication and database-backed features require Cloudflare setup and configuration. Only publish exam papers and other learning resources you have permission to redistribute; do not mirror third-party archives without authorization.
